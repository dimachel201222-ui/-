# 📸 ЧистеФото

Застосунок, який за пів хвилини робить чисте фото речі на білому фоні для оголошень.

## Проблема
Студент, який продає речі на OLX, хоче зробити охайні фото, але не вміє користуватися фоторедакторами, тому оголошення виглядають неакуратно і речі довго не купують.

## Рішення
Мій застосунок допомагає продавцям на OLX і в Instagram зробити фото речі на білому фоні за допомогою AI-видалення фону (rembg).

## Що вміє MVP (Must Have)
- [x] Завантажити фото речі (JPG/PNG)
- [x] Прибрати фон і отримати предмет на білому тлі
- [x] Завантажити готове фото у PNG

## Технології
Python, Streamlit, Pillow, rembg (модель u2netp, працює локально, API-ключ не потрібен).

## Як запустити
1. `pip install -r requirements.txt`
2. `streamlit run app.py`

Під час першого запуску rembg завантажить невелику модель (~4 МБ) — потрібен інтернет.
